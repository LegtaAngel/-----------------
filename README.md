# Сайт магазина обоев

Статический сайт без сборки и серверной части. Главная страница — `index.html`; каталог хранится в `content/wallpapers.json`, изображения — в `assets/`.

## Каталог

Товары редактируются в Decap CMS по адресу `/admin/`. Сайт загружает `content/wallpapers.json` и автоматически строит карточки и фильтры по коллекциям. В админке у каждого товара шесть полей: название, модель, дизайн, цена, остаток и картинка. Количество для исходных товаров пока неизвестно, поэтому показывается «Наличие уточняйте»; укажите остатки в админке.

## Настройка Decap CMS

1. В `admin/config.yml` укажите настоящий GitHub-репозиторий вместо `LegtaAngel/-----------------`.
2. В настройках GitHub OAuth App установите Authorization callback URL: `https://mrmissmit.vercel.app/api/callback`.
3. В Vercel задайте переменные окружения `OAUTH_CLIENT_ID` и `OAUTH_CLIENT_SECRET` из GitHub OAuth App, затем заново разверните сайт.
4. Опубликуйте файлы проекта в GitHub и разверните репозиторий на Vercel.
5. Откройте `https://mrmissmit.vercel.app/admin/`, войдите и редактируйте товары. CMS сохранит изменения в GitHub, после чего Vercel опубликует обновлённый каталог.

Функции `api/auth.js` и `api/callback.js` выполняют OAuth-переход и обмен кода на токен на сервере; секрет приложения не отправляется в браузер. Состояние OAuth защищено одноразовым `state` в HttpOnly cookie.

Загруженные через CMS картинки сохраняются в `assets/uploads/`.

## Публикация через GitHub Desktop и Vercel

1. В GitHub Desktop выберите **File → Add local repository** и укажите папку проекта. Если GitHub Desktop предложит создать репозиторий, выберите **Create a repository**.
2. Нажмите **Publish repository**, чтобы отправить проект в GitHub.
3. В Vercel создайте проект через **Add New → Project** и импортируйте репозиторий GitHub.
4. Оставьте Framework Preset как **Other** и не задавайте команду сборки.
5. Нажмите **Deploy**. Последующие изменения, отправленные в GitHub, будут публиковаться Vercel автоматически.
