# Сайт магазина обоев

Статический сайт: сборка и серверная часть не требуются. Главная страница — `index.html`, изображения и другие файлы находятся в `assets/`.

## Публикация через GitHub Desktop и Vercel

1. В GitHub Desktop выберите **File → Add local repository** и укажите папку проекта. Если GitHub Desktop предложит создать репозиторий, выберите **Create a repository**.
2. Нажмите **Publish repository**, чтобы отправить проект в свой аккаунт GitHub.
3. Войдите в Vercel, создайте новый проект (**Add New → Project**) и импортируйте опубликованный репозиторий GitHub.
4. Для статического сайта оставьте Framework Preset как **Other** и не задавайте команду сборки. Корень проекта содержит `index.html` и `vercel.json`.
5. Нажмите **Deploy**. Последующие изменения, отправленные в GitHub, будут публиковаться Vercel автоматически.

Vercel раздаёт сайт как статические файлы; здесь не нужно настраивать Render, Node.js-сервер или отдельную сборку.
